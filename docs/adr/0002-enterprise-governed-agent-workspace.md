# Build an enterprise-governed Agent workspace

ScopeGuard will differentiate through private or dedicated deployment,
replaceable Organization-approved model Providers, and first-class governed
Agents whose identity and authority remain stable across Model changes. The
Codex-like multi-conversation desktop layout is an interaction pattern rather
than the product's core value. This rejects positioning ScopeGuard as a general
multi-model Codex clone and keeps enterprise data boundaries, context
provenance, and tool policy central to subsequent design.
