# Historical UI Specification

This document previously described the first-stage Task, Artifact, Handoff,
Inbox, and Runtime UI. Those product concepts have been removed from the current
desktop core, so the old specification is intentionally retired.

The active UI direction is Workspace -> multiple persistent conversations, with
one to four conversations visible in parallel. Frontend behavior must follow the
current Renderer implementation and the product boundary in
[V2_ARCHITECTURE.md](./V2_ARCHITECTURE.md) until a new UI specification is
approved.
